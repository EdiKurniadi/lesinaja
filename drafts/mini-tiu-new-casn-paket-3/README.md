# Mini Try Out New TIU CASN — Paket 3 (Final)

Buka [draft.html](draft.html) untuk membaca 35 soal dan meninjau diagram. Kunci serta pembahasan tersedia pada setiap soal dan bisa dibuka sekaligus.

- [draft.json](draft.json): data soal, skor opsi, pembahasan, dan metadata draft.
- assets/: diagram SVG berlapis untuk soal dan opsi figural.
- figural.mjs: pola, pembahasan, dan pemeriksaan keunikan opsi figural.
- text-questions.mjs: sumber soal verbal, logika, dan numerik.
- [perubahan-pola.md](perubahan-pola.md): perbandingan cara berpikir sebelum dan sesudah revisi.
- generate.mjs: pembuat halaman tinjauan.

Komposisi mengikuti paket acuan: nomor 1–3 analogi; 4–8 logika; 9–12 hitung cepat; 13–18 deret, tabel, dan matriks angka; 19–30 soal cerita numerik (22–25 kecukupan data); 31–35 figural.

Durasi 30 menit. Benar 5, salah/kosong 0. Distribusi kunci: A, B, C, D, E masing-masing 7 soal.

Status: sudah diintegrasikan ke aplikasi melalui lib/mini-tiu-10-content.ts dan lib/content.ts. Kode akses: MTTIU3NIPSQUAD.
