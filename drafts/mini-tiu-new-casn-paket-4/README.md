# Mini Try Out New TIU CASN — Paket 2 (Final)

Buka [draft.html](draft.html) untuk meninjau 35 soal. Kunci dan pembahasan dapat dibuka per soal atau sekaligus. Gambar figural dapat diklik untuk diperbesar.

- 35 soal, durasi 30 menit, skor maksimum 175.
- Nomor 1–3: analogi; 4–8: logika dan susunan; 9–12: hitung cepat.
- Nomor 13–18: deret, tabel, matriks angka; 19–21: soal cerita numerik.
- Nomor 22–25: kecukupan data; 26–30: soal cerita numerik lanjutan.
- Nomor 31–35: analogi gambar, ketaksamaan, serial, dan dua matriks figural.
- Benar 5; salah/kosong 0. Kunci A–E masing-masing tujuh soal.

Data soal tersedia pada [draft.json](draft.json). Sumber teks pada text-questions.mjs dan diagram/model pada figural.mjs. Jalankan `node generate.mjs` dari direktori ini untuk membuat ulang draft, lalu `node validate.mjs` untuk pemeriksaan struktur dan model penalaran.
